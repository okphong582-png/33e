Cập Nhật Rules Cho Realtime Database

Rules khóa máy đầu tiên kích hoạt key. Chỉ quản trị viên được tạo, sửa hoặc gỡ khóa máy. Sao lưu Rules hiện tại trước khi áp dụng.

  1. Mở Firebase Console → Chọn dự án của bạn.
  2. Vào Build → Realtime Database → Chọn tab Rules (Quy tắc).
  3. Dán nội dung rules bên dưới vào rồi bấm Publish (Xuất bản):
{
  "rules": {
    ".read": false,
    ".write": false,
    "licenses": {
      "$keyHash": {
        ".read": true,
        ".write": false
      }
    },
    "licensesV2": {
      "$keyHash": {
        ".read": "$keyHash.matches(/^[a-f0-9]{64}$/)",
        ".write": false,
        ".validate": "newData.hasChildren(['enabled', 'expiresAt', 'protocol']) && newData.child('enabled').isBoolean() && newData.child('expiresAt').isNumber() && newData.child('protocol').val() === 2",
        "binding": {
          ".write": "$keyHash.matches(/^[a-f0-9]{64}$/) && !data.exists() && data.parent().exists() && data.parent().child('protocol').val() === 2 && data.parent().child('enabled').val() === true && data.parent().child('expiresAt').val() > now && newData.exists()",
          ".validate": "newData.hasChildren(['deviceHash', 'version', 'claimedAt'])",
          "deviceHash": {
            ".validate": "newData.isString() && newData.val().matches(/^[a-f0-9]{64}$/)"
          },
          "version": {
            ".validate": "newData.isNumber() && newData.val() === 1"
          },
          "claimedAt": {
            ".validate": "newData.isNumber() && newData.val() === now"
          },
          "$other": {
            ".validate": false
          }
        }
      }
    }
  }
}
